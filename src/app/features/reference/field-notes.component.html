Cargo commands

cargo new hello
Create a binary package.
cargo check
Type-check without producing an executable.
cargo run
Build and run your program.
cargo test
Run unit, integration, and documentation tests.
cargo fmt
Format your project with rustfmt.
cargo clippy -- -D warnings
Check common mistakes and reject warnings.
cargo doc --open
Build and browse project documentation.
cargo build --release
Build with the release profile.
rustup update stable
Update your installed stable toolchain.

Ownership and borrowing

  • Every value has an owner. When that owner’s scope ends, its value is dropped unless ownership was moved.
  • Moving transfers ownership. Copy types can be duplicated implicitly; Clone is explicit.
  • For ordinary references to the same value, use multiple shared borrows or one exclusive mutable borrow.
  • A reference must never outlive the value it points to. Lifetime annotations express relationships; they do not extend lifetimes.
  • Interior mutability permits mutation through shared references using types that enforce their own rules.
  • Model absence with Option and recoverable failure with Result. Use ? to propagate errors.
Version ≠ edition.

This course targets stable Rust 1.99.1, verified 22 October 2026, using edition 2024. The default runner image pins exactly that compiler, so the version shown in the header matches the course. The playground always uses stable Rust and edition 2024.

Local projects

The browser runner handles single-file examples and tests. Multi-file packages, procedural macros, custom dependency sets, real networking, embedded targets, Miri, and long-running services belong in a local Cargo project. 

cargo new rust-experiments
cd rust-experiments
# Copy your downloaded main.rs to src/main.rs
cargo run
cargo test
